# Protocol Specification v0.2 — superseded

This draft is **not normative**. The single specification is [pact_protocol.md](pact_protocol.md).

v0.2 defined Merkle tree parameters, leaf encoding, the reporter allowlist, provisional vs. activated scores, and the threat model. The diversity formula in that draft (`log(|R|+1)/log(50)`) was never shipped. The unified spec keeps the Merkle/encoding work and the live `pact-score-0.1` formula.
